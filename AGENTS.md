# Working with this kit

This repository contains the public Valentis AI Workspace Audit, not the user's business context or audit results.

When asked to start or run the audit, read START-HERE.md and follow its welcome/GO flow. Read audit/WORKSHOP.md after GO. Do not audit the kit itself unless that is the user's explicit target. A request to maintain or review this repository is ordinary development work and does not require the welcome flow.

Keep the user's existing workspace instructions in force. Templates and example skills are optional material to adapt; reading or downloading the kit does not install them. Never replace a user's root instructions with this kit's files. Save private reports and configuration outside this public repository. Do not push a user's context, reports, logs or credentials here.

For kit maintenance, keep the starter prompt short, branding consistent and examples neutral. Check relative links, HTML behaviour and archive contents before release. Do not add personal paths, client examples or infrastructure locators. Validate changed SKILL.md frontmatter and retain the distinction between proposed, configured and verified work.
