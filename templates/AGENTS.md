# Shared workspace instructions

Example to merge after the audit. Adapt it to the selected workspace; preserve useful existing guidance.

Find the selected business/client/project in the context map. Read applicable instructions and task-relevant sources. Ask when the target is ambiguous. Verify the tool/account identity before consequential actions.

Work from the brief, save the deliverable in its proper home and check it. Distinguish facts, hypotheses and proposals. Do not invent sources, customer quotes, performance figures or completed checks.

Keep instructions concise. Store durable decisions in the relevant context and check live state in its source. Save a short handover for unfinished work with output paths, actual checks and the exact next step.

Keep confidential client work in its own scope. Use actual account/file permissions for access boundaries. Keep secrets and login state out of shared context and version control. Respect HUMAN-ONLY material.

Follow the owner's approval requirements for external messages, publishing, spending, live account changes, destructive changes, new access and scheduled execution. Prepare concrete reviewable work before any required final approval. Existing permission applies within its agreed scope.
