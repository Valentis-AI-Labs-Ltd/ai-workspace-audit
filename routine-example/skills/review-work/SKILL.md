# Review the configured inputs

Read ../../ROUTINE.md, ../../GUARDRAILS.md and ../../maps/sources.md. Stop if required scope, dates, sources or destinations are missing. Use only the named inputs and verify workspace identity and freshness.

Compare supplied work against its configured brief or baseline. Draft the material observations, decisions needed and suggested next actions, grounded in the actual inputs. Distinguish facts from hypotheses; do not invent results or commitments.

Write only to agreed destinations. Record sources, outputs, checks and outcome: ok, partial, blocked or failed. Missing inputs cannot become a clean review. Record a run even when blocked, or explicitly report that evidence could not be written.
