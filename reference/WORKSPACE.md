# A workspace that helps you work

A useful AI workspace keeps the right background close to the work and makes it easy to continue tomorrow.

| Piece | Plain meaning | Example |
| --- | --- | --- |
| Workspace | The home for an area of work | One business, client or personal area |
| Instructions | How an assistant should work here | Standards, boundaries, where to find things |
| Context | Background and evidence for a task | A brief, brand guide, research or a past decision |
| Project | A particular outcome | A launch, a report or a product change |
| Skill | A reusable way to do a task | Reviewing a draft or preparing a brief |
| Routine | A method linked to a trigger | A weekly draft review with named inputs |
| Handover | Enough saved state to continue | Output, checks, decisions and the next step |

The chat is a working conversation. Files preserve useful background and decisions. Your task system owns assignments and status. Source tools own live metrics and accounts. Link them rather than maintaining competing copies.

Choose the smallest useful structure. One workspace can be convenient for a solo overview. Separate business/client workspaces can make sharing and account boundaries clearer. Keeping an existing structure with a better entry file is often a good first move.

Choose a location you can find, back up and open in your tools. Check who can access synced/shared folders before adding confidential work. Use real permissions for team and client boundaries.

A mature setup does not need lots of folders. A fresh assistant should find the right brief, make a useful output, check it and leave a clear next step.
