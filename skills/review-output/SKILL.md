# Review a deliverable

Resolve the selected workspace, candidate version, brief and requested scope. Load only relevant standards and sources. Review the actual output against the intended outcome and acceptance criteria.

Return the important findings with evidence and a practical fix. Separate performed checks from missing access, untested behaviour and specialist approvals still needed. Do not fabricate results or infer live performance from a draft.

Apply agreed draft fixes when requested and recheck the changes. Save the reviewed output and unresolved gaps. A review does not authorise external sending, publication or live account changes.
